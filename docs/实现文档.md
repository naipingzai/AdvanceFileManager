### 2.2 FFmpeg 原生库构建

FFmpeg 7.1 精简版通过 `materialfile_deps/native/ffmpeg/build.ps1` 交叉编译：

```powershell
# 基本构建
.\build.ps1

# 清洁重建
.\build.ps1 -Clean

# 指定 ABI
.\build.ps1 -Abi arm64-v8a
```

构建流程：
1. 使用 NDK 工具链（clang + llvm-ar/nm/ranlib/strip）
2. 通过 Git 内置 MSYS sh.exe 执行 FFmpeg configure
3. `--disable-everything` + 选择性启用所需编解码器
4. 编译产出静态库到 `prebuild/native/ffmpeg/`

#### FFmpeg 启用的组件

**解码器**：aac, mp3, flac, opus, vorbis, pcm_*, h264, hevc, vp8, vp9, av1, mpeg4, png, webp, gif + MediaCodec HW 解码器

**编码器**：aac, opus, pcm_s16le, flac, png, mjpeg, gif + MediaCodec HW 编码器 (h264/hevc/vp8/vp9)

**BSF**：aac_adtstoasc, h264_mp4toannexb, hevc_mp4toannexb, h264_metadata, hevc_metadata, extract_extradata

**协议**：仅 file（无网络）

## 3. 关键实现细节

### 3.1 文件系统层 (provider/)

#### LinuxFileSystemProvider

- 基于 `syscall.c` 中的 Linux 系统调用实现
- 使用 `opendir`/`readdir`/`stat`/`lstat` 等直接操作文件系统
- 通过 `inotify` 实现文件变化监听
- 支持所有 POSIX 文件属性：权限、所有者、SELinux 上下文

#### ArchiveFileSystemProvider

- 基于 `archive-jni.c`（libarchive 封装）
- 支持格式：ZIP, TAR, 7Z, RAR, GZIP, BZIP2, XZ, LZ4, ZSTD, CPIO, ISO
- 支持加密归档（通过 mbedTLS）
- 虚拟文件系统：将归档内容映射为目录树

#### Root/Remote Provider

- 通过 25 个 AIDL 接口实现跨进程文件操作
- 支持 Root (su) 和 Shizuku 两种特权模式
- 完整实现 NIO2 FileSystemProvider 接口的远程代理

### 3.2 文件操作层 (filejob/)

- `FileJobService`：前台服务，在通知栏显示操作进度
- `FileJob`：后台线程执行文件操作
- 支持的操作：复制、移动、删除、创建归档、解压、回收站
- 异常处理：冲突（覆盖/跳过/重命名）、权限不足、空间不足

### 3.3 FFmpeg JNI 层 (ffmpeg-jni.c)

#### 编解码器初始化

```c
JNI_OnLoad(JavaVM *vm, void *reserved)
  → av_jni_set_java_vm(vm, NULL)  // 注册 JavaVM 供 MediaCodec 使用
```

#### HW/SW 降级策略

```c
find_hw_encoder(codec_id)
  → 尝试 h264_mediacodec / hevc_mediacodec / ...
  → 失败则回退 SW encoder (libx264 等)

open_video_encoder_with_fallback(codec_id, ...)
  → attempt 0: HW encoder
  → attempt 1: SW encoder (if HW failed)
```

#### normalizeVideo 实现

1. 打开输入文件，找到视频/音频流
2. 初始化解码器（HW 优先 → SW 回退）
3. 初始化 H.264 编码器（目标分辨率/码率）
4. **延迟创建 sws_ctx**：等第一帧解码后根据实际像素格式创建
5. **HW 帧处理**：`av_hwframe_transfer_data()` 将 GPU 帧转为 CPU 帧
6. **宽高比保持**：计算 fit 尺寸 + letterbox/pillarbox 黑边填充
7. 像素格式转换 + 缩放：`sws_scale()` 到居中区域
8. 音频转为 AAC（通过 SwrContext 重采样）
9. 编码输出到 MP4

#### 视频合并实现 (mergeFiles)

- 使用 FFmpeg concat demuxer
- 生成临时 concat 列表文件
- 流拷贝模式（不重编码）

#### videoCompress 实现 (v1.1.0 新增参数)

```c
int videoCompress(JNIEnv *env, jclass clazz,
    jstring inputPath, jstring outputPath,
    jint targetBitrateKbps,
    jint targetWidth, jint targetHeight, jint targetFps,
    jobject callback)
```

1. 读取源视频分辨率和帧率
2. 如果指定 targetWidth/targetHeight，按宽高比缩放（保持偶数像素）
3. 如果指定 targetFps，通过 PTS 时间戳比较进行帧丢弃
4. 编码器 time_base = `av_inv_q(fr)`，适配 mpeg4 VOP 增量限制 (≤65535)
5. 解码循环：`AVERROR_INVALIDDATA` / `AVERROR(EINVAL)` 跳过（HW 解码器容错）
6. PTS 重缩放: `av_rescale_q(pkt->pts, in_stream->time_base, enc_ctx->time_base)`

#### GIF 生成修复 (gifMake)

- `av_frame_make_writable(scaled)` — 防止编码器差分优化引用共享缓冲区导致空帧
- `av_packet_rescale_ts(out_pkt, enc_ctx->time_base, out_stream->time_base)` — 编码器 1/fps 到 muxer 1/100 厘秒
- flush 循环同样需要时间戳重缩放

#### videoEnhance 实现

- 积分图 (Integral Image / SAT) O(1) 模糊：`apply_unsharp_plane()` 使用 Summed Area Table
- 每像素计算复杂度从 O(kernelW × kernelH) 降到 O(1)
- PTS 时基转换: 输入流 → 编码器

### 3.4 CSV 查看器实现

- **CsvViewerActivity** + **CsvViewerFragment**：WebView 渲染 HTML 表格
- **CSV 解析器**：状态机解析，支持引号字段内逗号、双引号转义
- **HTML 生成**：`buildHtmlTable()` 动态生成 HTML，注入 `body { padding-top }` 等于工具栏高度（dp）
- **暗色主题**：CSS `@media (prefers-color-scheme: dark/light)` 自动跟随系统
- **沉浸式**: FrameLayout 叠加工具栏 + WindowInsetsControllerCompat 点击切换
- **路由**：`FileListFragment.openFile()` 检测 `MimeType.isCsv` 跳转

### 3.6 视频播放器手势改进

- 左右滑动快进快退限制为 ±15 秒：`val maxSeekMs = 15_000L`
- 计算公式: `seekDelta = (deltaX / screenWidth * maxSeekMs).coerceIn(-maxSeekMs, maxSeekMs)`

实现为 `DialogFragment`，居中显示：

```kotlin
class OperationLogBottomSheet : DialogFragment() {
    // 样式: ThemeOverlay_Material3_MaterialAlertDialog
    // 背景: dialog_rounded_bg.xml (28dp 圆角)
    // 尺寸: 85% 宽 × 65% 高

    fun appendLog(message: String)           // 追加日志行
    fun setStep(name, current, total)        // 设置步骤描述
    fun setProgress(current: Int, total: Int)// 更新进度指示器
    fun finish(success: Boolean, error?: String) // 标记完成
    fun setOnCancelListener(listener)        // 取消回调
}
```

集成点：
- `MediaToolsFragment.doSmartMerge()` — 视频合并全流程
- `EncryptionFragment.executeProcess()` — 文件加密/解密

## 4. 依赖管理

### 4.1 本地依赖策略

项目采用**完全本地依赖**策略，所有第三方库均本地编译：

- **Java/Kotlin 库**：编译为 JAR，存放于 `prebuild/android/` 的 `libs/` 子目录
- **Android 库**：编译为 AAR，存放于 `prebuild/android/` 的 `libs/` 子目录
- **Native 库**：交叉编译为静态库 (.a)，存放于 `prebuild/native/`
- **修改的 AndroidX**：部分 AndroidX 源码内嵌修改（appcompat, swiperefreshlayout）

### 4.2 本地编译的 AAR 库 (22个)

photoview, libsu-core, libsu-service, speed-dial, subsampling-scale-image-view, licensesdialog, coil (5个), preferencex, simplemenu, advrecyclerview, materialshadownp, insetter (2个), shizuku (3个), androidsvg, drawer

### 4.3 官方依赖

通过 Maven 仓库引入的仅限 Google/JetBrains/AndroidX 官方库：
- AndroidX (core, appcompat, fragment, lifecycle, recyclerview, preference, media3, swiperefreshlayout)
- Material Components 1.12.0
- Kotlin stdlib + coroutines
- desugar_jdk_libs
